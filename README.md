# Python Login System

A beginner-friendly command-line login system built using Python. This project demonstrates the use of loops and conditional statements to implement basic username and password authentication.

 Features
- Username verification
- Password authentication
- Retry mechanism for incorrect passwords
- Welcome message after successful login
- Input validation using "if-else" statements

 Concepts Used
- Python Variables
- "while" Loops
- Nested Loops
- "if-else" Conditional Statements
- User Input ("input()")
- Output ("print()")

 How to Run
1. Clone this repository:
    git clone https://github.com/aayush02856-glitch/python-login-system.git

2. Navigate to the project directory:
   cd python-login-system

3. Run the Python file:
   python login.py

 Learning Purpose
This project was created as part of my Python programming practice to strengthen my understanding of loops, conditions, and basic authentication logic.
